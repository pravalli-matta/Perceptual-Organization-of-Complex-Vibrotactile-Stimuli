# Perceptual Organization of Complex Vibrotactile Stimuli

This project examined how people perceive and organize complex patterns of vibration. The work was carried out at the TaPer Lab, Centre for Cognitive and Brain Sciences, IIT Gandhinagar, under the guidance of Prof. Leslee Lazar (May–July 2026).

## Research Question

When a vibration is made up of multiple components, which physical features shape how similar or different it feels? The project explored how changes in temporal and spectral properties influence perceptual similarity.

## Experimental Approach

The work developed through three iterative pilot experiments. Vibrotactile stimuli were generated in Python and delivered using a HapCoil actuator. The stimulus set varied features including:

- Number of tones
- Inter-frequency interval (IFI)
- Amplitude-modulation depth
- Waveform shape
- Attack time

Fifteen participants made pairwise similarity judgements. These judgements were used to construct perceptual similarity matrices.

## Analysis

- **Non-metric multidimensional scaling (MDS):** used to represent the pairwise judgements as perceptual spaces.
- **Correlation and multiple regression:** used to examine relationships between physical stimulus properties and perceived similarity.
- **Representational Similarity Analysis (RSA):** used to compare the structure of physical stimulus descriptions with the structure of perceptual judgements.

## What This Work Examines

The project uses perceptual judgements to investigate how combinations of vibration parameters are represented in subjective experience. The analysis connects measurable stimulus properties with the similarities participants report; it does not directly measure neural activity or establish a neural mechanism for tactile perception.
